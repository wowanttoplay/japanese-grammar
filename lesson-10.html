第10课 · 存在与位置

学习目标能说明人和物的存在位置，并用方位词准确描述空间关系。

1. 場所 に N が あります

接续
场所 + に + 无生命事物 + が + あります
含义
表示某处存在物品、植物或没有自主移动能力的事物。

用法讲解

想告诉对方“某处有某物”，尤其是初次引入物品时，用「场所に＋物が＋あります」。地点由「に」标出，存在的无生命事物用「が」；书、建筑、植物等通常都用「あります」。

「机の上に本があります」把视线先放到桌上，再告诉听者那里有一本书。换成「部屋にテレビがあります」，即“房间里有电视”。若电视已是话题、只问它在哪儿，则说「テレビは部屋にあります」。

例句 · 听与读

  1. 01
    机つくえの 上うえに 本ほんが あります。
    桌子上有一本书。

使用提醒

存在地点用「に」；存在主体用「が」。
自测练习庭（　）木があります。显示答案⌄
庭に木があります。

2. 場所 に N が います

接续
场所 + に + 人／动物 + が + います
含义
表示某处有人或动物存在。

用法讲解

看见或介绍某处有人、动物时，用「场所に＋人／动物が＋います」。选择「います」看对象是否有生命并能自主移动，不取决于大小；老师、孩子、猫和鸟都用它，桌椅等物品则用「あります」。

「教室に学生がいます」是在教室这个范围内引入“学生”的存在，可译为“教室里有学生”。例如询问公园里有没有狗，可说「公園に犬がいますか」；回答不存在时用「いいえ、いません」。

例句 · 听与读

  1. 02
    教室きょうしつに 学生がくせいが います。
    教室里有学生。

使用提醒

有生命且能自主移动的对象通常用「います」。
自测练习公園に犬が（　）。显示答案⌄
公園に犬がいます。

3. N は 場所に あります／います

接续
已知对象 + は + 场所 + に + あります／います
含义
以已知的人或物为话题，说明其所在位置。

用法讲解

当人或物已经明确，重点是说明它“在哪里”时，把对象用「は」提出，再说「场所にあります／います」。无生命物选「あります」，人或动物选「います」；这与「场所にNが～」的信息焦点不同。

「郵便局は駅の前にあります」回答“邮局在哪儿”，不是介绍车站前有什么。换成人可说「田中さんは事務所にいます」，即“田中在办公室”。听到「Nはどこですか」时，按这个语序回答。

例句 · 听与读

  1. 03
    郵便局ゆうびんきょくは 駅えきの 前まえに あります。
    邮局在车站前面。

使用提醒

回答「Nはどこですか」时，常用这个语序。
自测练习田中さんは事務所（　）います。显示答案⌄
田中さんは事務所にいます。

4. N1 の 位置词

接续
参照物 + の + 上／下／前／後ろ／中／外／隣／近く
含义
以N1为参照点说明具体空间关系。

用法讲解

「上、下、前、後ろ、中、外、隣、近く」在日语里是名词，须用「の」把参照物和方位连接起来。位置总是相对于某物而言；只说「前です」时，需由上下文明确“谁的前面”。

「銀行はスーパーの隣です」中，超市是定位基准，银行在它旁边。也可说「スーパーの隣に銀行があります」，即“超市旁有银行”。「隣」多用于并排的同类地点，「近く」只表示附近。

例句 · 听与读

  1. 04
    銀行ぎんこうは スーパーの 隣となりです。
    银行在超市旁边。

使用提醒

方位词是名词，前面必须用「の」连接参照物。
自测练习猫は箱（　）中にいます。显示答案⌄
猫は箱の中にいます。

5. N1 や N2

接续
名词1 + や + 名词2 + など
含义
列举若干代表性事物，暗示还有其他同类。

用法讲解

列举几个代表项目、同时暗示还有其他同类事物时，用「N1やN2（など）」。这里「や」连接名词，「など」可放在最后把“等等”的意思说得更明确；如果要表示清单完整，才使用「と」。

「箱の中に写真や手紙があります」表示箱中有照片、信件之类，未必只有这两种。换一个场景可说「机の上に本やノートなどがあります」，即“桌上有书、笔记本等”。不要用「や」连接完整的两人组合。

例句 · 听与读

  1. 05
    箱はこの 中なかに 写真しゃしんや 手紙てがみが あります。
    箱子里有照片、信件等。

使用提醒

「と」倾向穷尽列举；「や」表示举例式列举。
自测练习机の上に本（　）ノートがあります。显示答案⌄
机の上に本やノートがあります。
