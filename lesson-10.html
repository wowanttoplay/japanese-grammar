第10课 · 存在与位置

学习目标能说明人和物的存在位置，并用方位词准确描述空间关系。

1. 場所 に N が あります

接续
场所 + に + 无生命事物 + が + あります
含义
表示某处存在物品、植物或没有自主移动能力的事物。

表示某处存在物品、植物或没有自主移动能力的事物。

  1. 01
    机つくえの 上うえに 本ほんが あります。
    桌子上有一本书。
使用提醒存在地点用「に」；存在主体用「が」。
自测练习庭（　）木があります。显示答案⌄
庭に木があります。

2. 場所 に N が います

接续
场所 + に + 人／动物 + が + います
含义
表示某处有人或动物存在。

表示某处有人或动物存在。

  1. 02
    教室きょうしつに 学生がくせいが います。
    教室里有学生。
使用提醒有生命且能自主移动的对象通常用「います」。
自测练习公園に犬が（　）。显示答案⌄
公園に犬がいます。

3. N は 場所に あります／います

接续
已知对象 + は + 场所 + に + あります／います
含义
以已知的人或物为话题，说明其所在位置。

以已知的人或物为话题，说明其所在位置。

  1. 03
    郵便局ゆうびんきょくは 駅えきの 前まえに あります。
    邮局在车站前面。
使用提醒回答「Nはどこですか」时，常用这个语序。
自测练习田中さんは事務所（　）います。显示答案⌄
田中さんは事務所にいます。

4. N1 の 位置词

接续
参照物 + の + 上／下／前／後ろ／中／外／隣／近く
含义
以N1为参照点说明具体空间关系。

以N1为参照点说明具体空间关系。

  1. 04
    銀行ぎんこうは スーパーの 隣となりです。
    银行在超市旁边。
使用提醒方位词是名词，前面必须用「の」连接参照物。
自测练习猫は箱（　）中にいます。显示答案⌄
猫は箱の中にいます。

5. N1 や N2

接续
名词1 + や + 名词2 + など
含义
列举若干代表性事物，暗示还有其他同类。

列举若干代表性事物，暗示还有其他同类。

  1. 05
    箱はこの 中なかに 写真しゃしんや 手紙てがみが あります。
    箱子里有照片、信件等。
使用提醒「と」倾向穷尽列举；「や」表示举例式列举。
自测练习机の上に本（　）ノートがあります。显示答案⌄
机の上に本やノートがあります。
